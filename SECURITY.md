# Security policy

## Reporting a vulnerability

Please do not open a public issue for security problems. Use GitHub's private
vulnerability reporting instead:

https://github.com/usehenri/henri/security/advisories/new

The report reaches the maintainer only. You should get an acknowledgement within
a week; a fix, an advisory and a release follow once the problem is confirmed.
If the form is unavailable, email the address listed in
[CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) with "security" in the subject.

## Supported versions

All `henri` and `@usehenri/*` packages share one version number.

| Version | Supported                                  |
| ------- | ------------------------------------------ |
| 1.x     | yes, on the latest 1.x release             |
| 0.x     | no, upgrade to 1.x (see the release notes) |

Security fixes ship as a patch release of the current 1.x line and are
announced through GitHub security advisories and the release notes.
