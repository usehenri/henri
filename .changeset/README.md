# Changesets

This folder is managed by [changesets](https://github.com/changesets/changesets).

- `pnpm changeset` records a version bump + changelog entry for the packages you touched.
- `pnpm changeset:version` applies pending changesets (bumps versions, writes CHANGELOGs).
- `pnpm changeset:publish` builds and publishes the bumped packages to npm.
