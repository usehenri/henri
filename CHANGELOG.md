# Changelog

All `henri` and `@usehenri/*` packages are released together with
[changesets](https://github.com/changesets/changesets). The changes of each
release are listed in:

- the GitHub releases: https://github.com/usehenri/henri/releases (one `v<version>` release per version)
- per package, `packages/<name>/CHANGELOG.md`, for example
  [packages/henri/CHANGELOG.md](packages/henri/CHANGELOG.md) and
  [packages/core/CHANGELOG.md](packages/core/CHANGELOG.md)

Releases before 1.0.0 (the lerna era, up to 0.37.2) are documented in the
[v0.37.2 tag](https://github.com/usehenri/henri/blob/v0.37.2/CHANGELOG.md).
